R.E.M

Controls: Arrows and Space

Cero numeral: Fire

History: A young student who falls 
asleep in class has to go through the different stages of 
sleep until reaching REM, facing challenges to finally wake up

The game was divided into 3 parts: Script, Code, and Animations. 
Each member focused on creating their part of the project while guiding each other, 
the code mainly has functions and conditions with their respective variables and objects.
